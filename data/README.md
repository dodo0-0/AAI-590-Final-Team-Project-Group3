# Local data

Raw data is not supplied through Git. Keep it outside Git; this directory ignores all
contents except this README. An external dataset directory is also acceptable.
Do not fabricate a sample to stand in for dataset evidence. Record the actual
location and provenance in the dataset inventory when available.

The prepared team Drive bundle restores the selected radio subset under
data/radio/. See [the handoff guide](../docs/handoff.md). The full Kaggle archive
is not required for the current radio audit and is excluded from that bundle.
