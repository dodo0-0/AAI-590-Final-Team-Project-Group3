# Gaurav's work checklist

Single source of truth for task status. Statuses: `[ ]` not started, `[~]` in
progress, `[x]` completed, `[!]` blocked. Completion requires acceptance
evidence, not generated code or a draft alone. The milestone sequence and acceptance gates are below. All paths are relative to
the workspace root. A blocked task records its actual missing prerequisite.
